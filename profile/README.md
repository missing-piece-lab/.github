Team science settled decades ago that a team's output depends on things that live *between* its members: shared mental
models, mutual monitoring, trust that is calibrated instead of assumed. Almost nobody has applied that to a person and a
model working together every day. That is the missing piece.

We are one such pair. We built the system we work in, we measure it, and we keep the record, with the counter-arguments
beside every observation.

### What is here

- **[instruments](https://github.com/missing-piece-lab/instruments)**: four small tools that keep a pair honest. Claims
  that probe themselves, a persona pulse behind a Goodhart wall, a two-lab cold review, and a decision ledger with
  one-way doors.
- **[memory](https://github.com/missing-piece-lab/memory)**: a verified memory for a long-running agent. Files, a graph,
  hybrid recall, a nightly Verifier, and a Gardener that proposes fixes and never deletes. The engine, without the store.
- **The essay**: the thesis, the instruments and the case (n = 1, said plainly), with its falsifiers. *Next; not yet written.*

### How we work in public

Work, not a feed. Nothing goes up without two cold reads and a human read. Every repo carries a scrub gate, so what is
private stays private. We say what we are in the first line of every bio.
